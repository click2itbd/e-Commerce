# 02. State Machine & Business Logic Flows

## 1. Product Availability & Checkout Gate State Machine

```
[Product in Firestore]
   ├── isOutOfStock === true   ──► Storefront Badge: "OUT OF STOCK" (Cart & Checkout BLOCKED)
   └── isOutOfStock !== true   ──► Storefront Badge: Available (Even if stock <= 0, Cart & Payment ALLOWED)
```

- **Rule:** Never block cart addition, checkout, or payment on `product.stock <= 0`. Only block when `Boolean(product.isOutOfStock) === true`.

## 2. Order Lifecycle & Stock Deduction State Machine

```
[Online Order Placed]
   │
   ▼
status: "pending" (stockDeducted: false)
   │
   ├──► Admin sets status: "processing"
   │       ├── Check: if (!order.stockDeducted)
   │       ├── Action: Deduct item quantities from `products/{id}.stock` (clamped to >= 0)
   │       └── Flag: Set `order.stockDeducted = true`
   │
   ├──► Admin sets status: "shipped" / "delivered" / "completed"
   │       └── If `!order.stockDeducted`, deduct stock once and set `stockDeducted = true`
   │
   └──► Admin sets status: "cancelled" / "returned"
           ├── Check: if (order.stockDeducted)
           ├── Action: Restore item quantities back to `products/{id}.stock`
           └── Flag: Set `order.stockDeducted = false`
```

- **In-Store / Admin Direct Sale (`SalesForm.tsx` / `POS`):**
  - Deducts stock immediately upon invoice creation (`stockDeducted: true`) and removes sold serials from `availableSerials`.
  - When editing an existing invoice in `SalesForm.tsx`:
    - Normalizes `item.id = item.id || item.productId` and `item.productId = item.productId || item.id`.
    - Reconciles stock delta between original items and updated items.
    - Updates the linked `sale` transaction in `transactions` collection (matching `referenceId === order.id` or `documentNumber`).

## 3. Address Book & Checkout Auto-Fill State Machine

```
[User Enters Checkout Page]
   ├── Saved Addresses == 0 ──► Empty form (User selects Division -> District -> Upazila -> Union -> auto-postcode)
   ├── Saved Addresses == 1 ──► Auto-fills form immediately with the saved address
   └── Saved Addresses >= 2 ──► Auto-fills default address + Renders "Select Saved Address" card picker
```

## 4. Ledger & Party Statement State Machine

```
[Entity Selected in Ledger]
   ├── selectedLedgerEntity.isCompany === true
   │      └── Corporate Rollup Mode: Aggregates all customers & transactions matching `companyKey`
   │
   └── selectedLedgerEntity.isCompany !== true (Individual Customer / Vendor)
          ├── Strict Entity Match: `t.entityId === id` OR `t.entityName.toLowerCase() === name.toLowerCase()`
          ├── Project Filter Dropdown: Shown ONLY if `availableProjects.length > 0` for THIS customer
          └── Never merges transactions from other customers sharing the same `company` string
```
