# 04. Technology Stack & Framework Versions

## Core Runtime & Frontend
- **Framework:** React `^19.0.0` + React DOM `^19.0.0`
- **Language:** TypeScript `~5.8.2`
- **Bundler:** Vite `^6.2.0` (`@vitejs/plugin-react` `^5.0.4`)
- **Routing:** `react-router-dom` `^7.13.2`
- **Styling:** Tailwind CSS v4 (`tailwindcss` `^4.1.14`, `@tailwindcss/vite` `^4.1.14`, `clsx`, `tailwind-merge`)
- **Animations & 3D:** `framer-motion` `^12.38.0`, `three` `^0.186.0`, `@react-three/fiber` `^9.7.0`, `@react-three/drei` `^10.7.8`
- **Icons:** `lucide-react` `^0.546.0`
- **Notifications:** `react-hot-toast` `^2.6.0`

---

## Backend, Database & Cloud Services
- **Client SDK:** `firebase` `^12.11.0` (Firestore with persistent local cache, Firebase Auth, Firebase Storage, Cloud Functions)
- **Server / Admin SDK:** `firebase-admin` `^14.3.0`
- **Backend Server:** Express `^4.22.1` executed via `tsx` (`server.ts` / `backend/src/server.ts`)
- **AI Integration:** `@google/genai` `^1.29.0`
- **Email & Alerts:** `nodemailer` `^10.1.1`, `resend` `^6.10.0`

---

## Reporting, PDF & Utilities
- **PDF Generation:** `jspdf` `^4.2.1` + `jspdf-autotable` `^5.0.7` (`src/utils/pdf.ts`)
- **Charts & Analytics:** `recharts` `^3.8.1`
- **CSV Import/Export:** `papaparse` `^5.5.3`
- **Testing:** `vitest` `^4.1.11`, `@playwright/test` `^1.62.1`

## Build & Verification Commands
- **Start Dev Server:** `npm run dev` (or `npx tsx server.ts`)
- **Production Build Check:** `npm run build` (uses `4096MB` max-old-space-size)
- **Type Check:** `npm run lint` (`tsc --noEmit`)
