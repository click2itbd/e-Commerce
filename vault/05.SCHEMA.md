# 05. Firestore Database Schema

## Primary Collections

### 1. `products` (`Product`)
- `id`: string (Document ID)
- `name`, `sku`, `barcode`, `model`, `brand`, `category`, `subCategory`, `subSubCategory`: string
- `price`: number, `discountPrice?`: number, `costPrice?`: number
- `stock`: number (Current inventory count)
- `isOutOfStock?`: boolean (**Master storefront stock lock** — when `true`, product cannot be ordered)
- `hasSerialTracking?`: boolean, `availableSerials?`: string[]
- `warrantyMonths?`: number, `warrantyUnit?`: `'days' | 'months' | 'years'`
- `images`: string[], `specs?`: `Record<string, string>`

### 2. `orders` (`Order`)
- `id`: string (Document ID)
- `documentNumber`: string (Unique formatted ID, e.g. `INV-00202`, `QUO-00045`)
- `type`: `'invoice' | 'quotation' | 'challan' | 'sale' | 'pos_sale' | 'pc_build'`
- `status`: `'pending' | 'processing' | 'accepted' | 'completed' | 'shipped' | 'delivered' | 'cancelled' | 'returned'`
- `stockDeducted?`: boolean (Tracks whether inventory has been deducted for this order)
- `customerId`: string, `customerName`: string, `customerPhone`: string, `customerEmail`: string, `shippingAddress`: string
- `company?`: string (e.g. `'main'`, `'simpletree'`, `'spacezero'`, `'volumezero'`)
- `branchName?` / `projectName?`: string (Sub-branch or project under the customer)
- `items`: `CartItem[]` (Note: items may carry `id` and/or `productId` — always normalize `const pid = item.id || item.productId`)
- `subtotal`: number, `discountAmount?`: number, `total`: number
- `paidAmount`: number, `paymentStatus`: `'paid' | 'partial' | 'unpaid' | 'due'`

### 3. `customers` (`Customer`)
- `id`: string (Document ID)
- `name`, `phone`, `email`, `address`: string
- `company?`: string (Business unit tag, defaults to `'main'`)
- `branchName?`: string (Primary branch/project name)
- `branches?`: string[] (List of branches/projects under this customer)
- `loyaltyPoints?`: number, `createdAt`: string

### 4. `transactions` (`Transaction`)
- `id`: string (Document ID)
- `type`: `'sale' | 'purchase' | 'expense' | 'income' | 'payment_received' | 'payment_made' | 'money_receipt' | 'sale_return' | 'purchase_return' | 'opening_balance'`
- `amount`: number, `date`: string (ISO), `createdAt`: string
- `entityId`: string (Customer ID or Vendor ID)
- `entityName`: string
- `entityType?`: `'customer' | 'vendor'`
- `documentNumber?`: string (e.g. `INV-00202`), `referenceId?`: string (Order Doc ID)
- `company?`: string, `branchName?`: string, `projectName?`: string
- `paymentAccountId?`: string, `paymentMethod?`: string

### 5. `vendors` (`Vendor`) & `purchases` (`Purchase`)
- Tracks supplier profiles, purchase bills (`PUR-XXXXX`), serial number intake, and vendor payable ledgers.

### 6. `users` (`UserProfile`)
- `uid`, `email`, `displayName`, `role` (`'admin' | 'manager' | 'staff' | 'user'`), `permissions`: string[]
- `savedAddresses?` / `addresses?`: Array of user delivery addresses (`label`, `fullName`, `phone`, `division`, `district`, `upazila`, `union`, `postcode`, `address`, `isDefault`).

### 7. `settings` & `counters`
- `settings/general`: Global site configuration, invoice terms, payment methods, courier config.
- `counters/{type}`: Atomic sequence counters for `INV`, `QUO`, `CHL`, `PUR`, etc.
